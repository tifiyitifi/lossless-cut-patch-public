- Fork patch release: verify with the new Windows auto-tag release CI (`release` branch -> `v3.69.1`)
- Project file (`.llc`): the segment times can now be written as readable timecodes (`00:00:00.000000000`, project version 3) instead of plain numbers of seconds. Both are read back identically; loading still accepts v1 and v2. The numeric format stays the default (version 2, openable by older versions and upstream); switch the setting to "Timecode (readable)" when you want the readable format. The readable format needs this build to open.
