## English

First public release of **LosslessCut-Patch**, a Windows x64 fork of LosslessCut 3.70.2. It keeps the upstream lossless editor and adds **patch mode**, a guided workflow for cutting many videos in batches. Switch to the upstream interface at any time with **Mode → Base mode**.

- **Patch mode is the default** — one working directory per batch, with a source file list and one cut list per source.
- **Cut → merge → finish** — `E` exports the queued cuts, `E` in the cut-results window merges them, and `Shift+E` opens the finish dialog: the kept files move to the finished folder and the next source opens.
- **Incremental exports** — add or change clips and export again; only the clips that changed are cut again.
- **Separate result windows** — cut and merged results get their own player, playlist and shortcuts, so you can review them while the source stays open.
- **Work and finished folders** — `.losslesscut_work` and `losslesscut_finished` by default, with configurable names; videos inside them are read-only so they cannot be cut again by accident.
- **Source list** — sort by name, extension, size, modification time or duration, see each file's duration, size and modification time in its row, and drag the list wider.
- **Finish options** — cut results are renamed as they move (`{source}-clip-{seg_num}` by default); an existing merged result can be moved to `finished_merged`, deleted, or left where it is.
- **One export at a time** — the finish dialog moves only this export's cut results to `finished_clips`. Results from earlier passes are deleted when the job moves on to the next video, or kept in the work area while you keep working on the same one (a checkbox in `Cut clips` overrides it). A result missing from an earlier pass no longer blocks the finish.
- **Counts you can tell apart** — the section lists this export's cut results, earlier passes' temporary clips and the total separately, and each group names its action (`move to finished_clips` / `permanently deleted`).
- **Results from earlier finishes** — a line lists the results an earlier finish already moved to `finished_clips` (hovering shows the files; segments this export cuts again are left out), so the work-area count can be compared with the project file.
- **Deletion check keeps every pass** — a source moved inside the work area is recognised by its exact size and a fingerprint of its head and tail, so the results of every pass stay together instead of only the last one.
- **Accurate checks and menus** — the permanent-delete confirmation reports only the space a job really frees, and a source row's right-click menu (including Clear) stays available when the list is full.
- **Deletion check** — one grid of sources and their results with thumbnails, sizes and durations, a full decode check, and multi-select. It shows which sources are safe to delete because their kept results are still on disk; deleting moves the source video to a waiting-for-deletion folder instead of erasing it, and results follow the dialog's delete-or-move choice.
- **Damaged sources** — detect and repair a damaged first GOP, copy a recoverable file, or play through a re-encoded preview; the original file is left untouched.
- **Time tools and project files** — turn hand-written time pairs into cut points or a project file (and back), open `.llc` cut lists together with their source, and use an optional readable timecode format (older numeric files still load).
- **Keyboard and console** — patch mode has its own layout (X/Z/C speed, Ctrl+E snapshot, F/D frame step) beside the upstream keys, customizable bindings, and a command console on `Shift+Space` with aliases.
- **Updates** — Help → Check for updates reads this fork's GitHub releases, not the official app's, and can download and install a verified update in place.
- **Windows x64 only** — portable 7z/zip, no installer, FFmpeg bundled. The build is unsigned, so SmartScreen may warn; compare `SHA256SUMS.txt` to verify a download.
- **Chinese UI** — patch-mode windows, dialogs and help are available in Simplified and Traditional Chinese, with English fallback.

## 中文

**LosslessCut-Patch** 首个公开版本，基于 LosslessCut 3.70.2 的 Windows x64 分支。保留上游的无损剪辑功能，并加入 **patch 模式**：面向批量剪片的引导式流程。随时可以用 **Mode → Base mode** 切回上游界面。

- **默认进入 patch 模式** — 一个批次一个工作目录，带源文件列表，每个源文件一份剪切表。
- **剪切 → 合并 → 收尾** — `E` 导出队列中的切片，在切片结果窗口按 `E` 合并，按 `Shift+E` 打开收尾对话框：保留的文件移到成品目录，并打开下一个源。
- **增量导出** — 增删或修改切片后再次导出，只重切有变化的片段。
- **独立的结果窗口** — 切片结果和合并结果有自己的播放器、播放列表和快捷键，可以在源窗口保持打开时审片。
- **工作目录与成品目录** — 默认 `.losslesscut_work` 和 `losslesscut_finished`，名称可配置；其中的视频是只读的，避免误操作再次剪切。
- **源文件列表** — 可按名称、扩展名、大小、修改时间或时长排序；每行显示时长、大小和修改时间；列表宽度可拖动。
- **收尾选项** — 切片结果移动时按 `{source}-clip-{seg_num}` 重命名（默认）；已有合并结果可以移到 `finished_merged`、删除或留在原处。
- **一次只收尾本次导出** — 收尾对话框只把本次导出的切片移到 `finished_clips`。之前批次的结果在任务进入下一个视频时删除，留在同一个视频上继续处理时则保留在工作区（`Cut clips` 区的复选框可以覆盖）。之前批次缺少某个结果也不再阻止收尾。
- **数字分开显示** — 该区域分别列出本次导出的切片、之前批次的临时切片和总数，每组都标明动作（`移到 finished_clips` / `永久删除`）。
- **之前收尾过的结果** — 会列出这个源已经被之前的收尾移到 `finished_clips` 的结果（悬停显示文件；本次重新剪的片段不算），方便把工作区数量与项目文件对照。
- **删除检查保留每一轮的结果** — 收尾任务在工作区内移动源视频后，删除检查会用精确大小和头尾指纹重新识别它，让每一轮的结果都归在同一个源下。
- **更准确的提示** — 永久删除确认只统计任务真正释放的空间；源文件行在列表铺满时右键菜单（包括 Clear）仍然可用。
- **删除检查** — 用一张网格展示源文件及其结果，带缩略图、大小和时长，支持全片解码校验和多选。它会标出哪些源可以安全删除（保留的结果仍在盘上）；删除时源视频只是移到待删目录，不会立即抹掉，结果按对话框的选择删除或移走。
- **损坏源处理** — 检测并修复损坏的第一个 GOP、复制可恢复的文件，或用转码预览播下去；原文件保持不变。
- **时间工具与项目文件** — 把手写的时间对转换为切片点或项目文件（也能反向转换）；`.llc` 剪切表会连同源文件一起打开；可选可读时间码格式，旧版数字格式仍可读取。
- **键盘与命令台** — patch 模式有自己的一套按键（X/Z/C 速度、Ctrl+E 截图、F/D 逐帧），与上游按键并存；可自定义绑定；`Shift+Space` 打开带别名的命令台。
- **更新** — Help → Check for updates 只检查本 fork 的 GitHub release，不会把官方版当更新；可以在应用内下载并安装经过校验的更新。
- **仅 Windows x64** — 便携版 7z/zip，无安装程序，内置 FFmpeg。构建未签名，SmartScreen 可能提示；可用 `SHA256SUMS.txt` 校验下载。
- **中文界面** — patch 模式的窗口、对话框和帮助支持简体中文和繁体中文，英文为后备。
